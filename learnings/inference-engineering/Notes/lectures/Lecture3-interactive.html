Sector 1Parts 1–5 · The machinery that computes gradients
01

Derivatives as perturbation

Nudge the input, watch the output
Briefing
  • A derivative answers one question: if I nudge this input by a tiny amount, how much does the output move?
  • Central difference: (f(x+h) − f(x−h)) / 2h. Its error terms cancel, so it beats the one-sided version.
  • Hand derivatives are sums over every place a variable appears. a sits in (a+b)² and in a·c/d, so its derivative has two terms. That is why gradients must accumulate later.
  • Numerical gradients cost two forward passes per parameter. Backprop gives all gradients in one forward and one backward pass. The numerical method survives only as a test.
expr = ((a+b)**2) + (a*c)/d + d + b/2 # a=3, b=10, c=12, d=4 -> 187
02

The graph and the chain rule

Local derivatives, glued together
Briefing
  • Every expression is a graph. Leaves are inputs or parameters. Intermediate nodes come from an operation on its inputs.
  • The graph is a DAG, not a tree. a, b and d in the tanh expression each have two outgoing edges.
  • Constants are nodes too. b/2 creates an extra node 2**-1.
  • You never differentiate the whole expression. Each node only knows its local derivative.
final gradient = upstream gradient × local derivative
OpLocal derivative
a + b1 and 1 (a router)
a * bb for a, a for b (swaps)
a ** nn · a^(n−1)

03

The Value class

Forward operations with a closure attached
Briefing
  • A Value stores value, children (the graph edges), _backward (a closure with this one op's rule) and grad.
  • Each op does three things: compute the forward value, record the inputs, attach a closure.
  • The closure is defined inside the operator, so it captures self, other and out exactly as they were.
  • Subtraction is a + b*-1. Division is a * b**-1. They inherit correct gradients for free.
  • The exponent in __pow__ is a constant. other.grad stays 0, which would be wrong for 2**x.
def __mul__(self, other):
    other = self._clean(other)
    out = Value(self.value * other.value, children=(self, other))
    def backward():
        self.grad  += other.value * out.grad
        other.grad += self.value  * out.grad
    out._backward = backward
    return out
04

Reverse-mode backward()

Seed, order, accumulate
Briefing
  • Seed the output with 1 because ∂L/∂L = 1. A seed of 0 makes every gradient 0.
  • Topological order, then reverse. A node may push gradient to its inputs only after every consumer has pushed into it.
  • Accumulate with +=. A value reaching the output through several routes gets the sum of the routes. y = x + x must give 2.
  • backward() never clears grad. Call it twice and non-root gradients double. Clearing is the caller's job.
05

Neuron, Layer, MLP, one loop

Forward, loss, zero, backward, update
Briefing
  • Neuron(nin): nin weights and one bias, output tanh(w·x + b). MLP([3,4,4,1]) has (3·4+4)+(4·4+4)+(4·1+1) = 41 parameters.
  • Why a bias: without it, all-zero input forces zero output. Why a nonlinearity: two stacked linear layers are one linear layer.
  • The graph is rebuilt every iteration. Only parameter values persist.
  • The update p.value += -lr * p.grad edits a plain number outside the graph. The gradient points toward increasing loss, so you step against it.
Sector 2Parts 6–10 · The bigram language model, two ways
06

From autograd to language

Pairs, boundary tokens, vocabulary
Briefing
  • A language model estimates the next-token distribution. A bigram assumes only the previous token matters: P(xₜ | x₁…xₜ₋₁) ≈ P(xₜ | xₜ₋₁).
  • Each name is wrapped as . name .. For emma that gives 5 pairs, len(word) + 1. Over 32,033 names that is 228,146 pairs.
  • . is an input at the start and a target at the end, so the model learns when to stop.
  • Vocabulary V = 27: . → 0, a → 1 … z → 26. A token ID is just an integer with no meaning.
07

The count-based bigram

A 27×27 table of counts
Briefing
  • Row i is the previous character, column j the next. N[i,j] counts how often j followed i. The whole model is 729 numbers.
  • Normalize with N / N.sum(dim=1, keepdim=True). Each row becomes a distribution. Without keepdim=True the shape [27] aligns with the last axis and divides the wrong totals, silently.
  • dim=0 gives P(previous | next). Legit, but not what generation needs.
  • Sampling is autoregressive: sample from row idx, feed the result back in as the next row. The generator is stateful, so an extra multinomial call changes every later sample.
  • Counts stored in FP16 silently round. 4410 becomes 4408.
08

NLL and smoothing

How surprised is the model by real data?
Briefing
  • Likelihood is the product of the probabilities the model gave to every observed pair. A product of 228,146 numbers below 1 underflows, so take the log (a sum), negate it, and average.
  • NLL = −(1/M) Σ log P(yₘ | xₘ)
  • The uniform model gives log V = log 27 = 3.296. Anything that cannot beat it has learned nothing. Count model with α=1 on the full data: 2.4544.
  • α=0 leaves zero-probability cells and log 0 = −inf. Training NLL never evaluates the unseen pairs, so it cannot see this. Held-out data can.
  • Larger α pulls every row toward uniform. Huge α drives NLL toward 3.296.
09

The neural bigram

Learn the table with gradient descent
Briefing
  • xenc = one_hot(xs) [M,27], logits = xenc @ w, counts = logits.exp(), prob = counts / counts.sum(1, keepdim=True).
  • one_hot(x) @ W is row x of W. A matrix multiply is a table lookup in disguise.
  • Logits are not probabilities. exp makes them positive (the "count"), the row-sum division normalizes them. Together that is softmax.
  • prob[arange(M), ys] picks the probability given to the correct next character.
  • Real runs: 100 steps, lr = 50 (the loss is a mean, so gradients are tiny), loss starts at 3.7686 and ends at 2.4901 (with the L2 term). The count model had 2.4544.
10

Why they are one model

Smoothing and L2 share an instinct
Briefing
  • Softmax of a row is exp(W[x,y]) / Σⱼ exp(W[x,j]). Set W[x,y] = log(N[x,y] + α) and it equals the smoothed count formula exactly.
  • The two differ only in how the parameters are found: counted in one pass, or found by gradient descent.
  • Smoothing pulls rows toward uniform. An L2 penalty pulls W toward 0, which makes logits equal, which makes softmax uniform. Bigger λ ≈ bigger α.
  • Same seed on both samplers means the same random numbers hit nearly the same slices. Identical samples are weak evidence. Compare the losses.
  • Use F.cross_entropy(logits, ys) on raw logits. It fuses log-softmax with NLL via log-sum-exp. The hand path overflows at exp(100).

Sector 3Parts 11–14 · A fixed-context MLP with embeddings
11

Windows and splits

block_size = 3 previous characters
Briefing
  • A bigram cannot tell ann from kin. A window of the last 3 characters can.
  • A count table over 3 characters needs 27³ = 19,683 rows, mostly unseen. Learned embeddings let similar contexts share parameters.
  • The script pads with one . each side and loops len(word) − block_size times. So the first letters are never targets and the context [. . .] is never trained. Padding with block_size dots gives len(name) + 1 examples.
  • Train updates weights, dev chooses hyperparameters, test is seen once. The script splits 80/10/10 over unshuffled examples. A shuffled word-level split is better.
12

Embeddings and the shape path

From IDs to logits
Briefing
  • C is [27,10]. C[xdata] is [B,3,10]. It is the same row selection as one_hot @ W, without the one-hot.
  • Flatten with .view(-1, 30). No parameters. Position is kept by where each embedding sits: 0–9 oldest, 20–29 newest.
  • A longer context grows only W1, whose first dimension is T·emb_size.
  • Gradients reach only the selected rows of C. A character used twice in a batch gets both contributions added.
  • Parameters: 270 + 6000 + 200 + 5400 + 27 = 11,897.
13

Training the MLP

Mini-batches, schedules, held-out loss
Briefing
  • Same five steps, plus a mini-batch: 8 random examples per step. The gradient is a noisy estimate that points the right way on average.
  • Mini-batch loss is noisy. Group and average, or evaluate full splits under torch.no_grad(). avg_losses[-1] is a training signal over the last 1000 steps.
  • Without tanh between layers, (xW1+b1)W2+b2 collapses to one linear map. With randn weights, pre-activations start large, so tanh starts saturated.
  • The schedule bug: lr = 0.1 if i < 100000 else 0.01 tested a leftover i. No error, no decay.
  • Train 2.0133 · Dev 2.4013 · Test 2.4281. The gap mixes overfitting with an unshuffled split.
  • Softmax is for sampling. Training passes raw logits to the loss.

Spot the bug

Mistakes that appear when you write this code
Briefing
  • Autograd: reverse operators are not all symmetric, -x and 2/x need their own methods, tanh via exp(2x) overflows, gradients never reset themselves.
  • Bigram: right axis plus keepdim=True, no FP16 counts, a stateful generator, compare losses on the same data.
  • MLP: pad with block_size boundary tokens, shuffle then split, full dev evaluation, nonlinearity between layers, schedule on the loop counter, seed every random source, raw logits to the loss.

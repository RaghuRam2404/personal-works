Markov Chains

"To predict what happens next, you only need to know
where you are right now."

A profound idea from probability theory: systems where the present state carries all the information you need — the entire past becomes irrelevant.

Starting From First Principles

Can you predict tomorrow
without knowing all of yesterday?

Look at the weather over the past few weeks. It changes day by day — seemingly random. But is it completely unpredictable?

The Key Observation
To guess tomorrow's weather, knowing today is enough.
Last week? Last month? They add nothing.

P(tomorrow | today, yesterday, ...) = P(tomorrow | today)
The past collapses into the present. Only NOW matters.

Building Block #1

What is a State?

A Markov chain lives in a finite set of states — distinct conditions the system can occupy. At every moment, the system is in exactly one state.

🌤️
Weather Model
States: Sunny, Cloudy, Rainy
At any moment the sky is exactly one of these. It cannot be "half-sunny, half-cloudy."
🐸
Frog on Lily Pads
States: Pad A, Pad B, Pad C
The frog is always on exactly one pad. Each jump moves it to another — or it stays.
🌐
Web Surfer
States: Page 1, Page 2, ..., Page N
A reader clicking links is always on exactly one page. Each click is a transition.
▼
The Core Idea

The Markov Property

This is the one rule that defines a Markov chain. If a system obeys this rule, all the powerful machinery of Markov theory applies.

P(Xn+1 = j | Xn = i, Xn−1, ..., X0) = P(Xn+1 = j | Xn = i)
The probability of the next state depends only on the current state — not on how you got here.
🧠
Has Memory (Not Markov)
A person's health depends on last week's sleep, last month's diet, years of habits. History matters — not Markov.
🎲
Memoryless ✓ Markov!
A die roll: the outcome only depends on the current state of the die — not on the last 100 rolls. No history needed.
▼
Building Block #2

Transition Probabilities

From each state, the system moves to another (or stays) with fixed probabilities. These transition probabilities are the complete rulebook of the chain.

Golden Rule
For each state i, all outgoing probabilities must sum to exactly 1:
∑ⱼ P(i → j) = 1
The system always goes somewhere — even staying put counts as a self-transition.

The Mathematics

The Stationary Distribution

Those long-run frequencies are not random — they're the unique solution to an equation. A distribution π is stationary if applying one more step of P leaves it unchanged.

π P = π    and    ∑ πᵢ = 1
If the chain's current distribution is π, one more step produces exactly π again. The chain has reached equilibrium.
☀️
π(Sunny) = 9/22 ≈ 40.9%
In the long run ~41% of days are sunny. This holds no matter where the chain started — sun, cloud, or rain.
☁️
π(Cloudy) = 7/22 ≈ 31.8%
~32% of days are cloudy. The stationary distribution is entirely determined by the transition matrix.
🌧️
π(Rainy) = 6/22 ≈ 27.3%
~27% of days are rainy. The chain "forgets" where it began and converges to the same equilibrium.

Classifying States

Transient vs Recurrent

Not all states are created equal. Some you will always return to. Others you might visit once and escape from forever.

🔄
Recurrent State
Starting here, you return with probability 1. You'll visit this state infinitely often.

Like a closed loop — you always come back.
🚀
Transient State
Starting here, there is a nonzero chance you never return. Eventually the chain escapes it permanently.

Like a stepping stone — you pass through and move on.
🧩
Irreducible Chain
If every state can reach every other state, the chain is irreducible — all states are recurrent and there is a unique stationary distribution.

Applications

Markov Chains are everywhere

From how Google ranks websites to how language models generate text — the same simple idea appears across all of science and technology.

🔍
Google PageRank
A "random web surfer" jumping between pages is a Markov chain. The stationary distribution gives each page its rank. That's what Google Search computes.
🧬
DNA Mutation
Genetic mutations over the alphabet {A, T, C, G} are modeled as a Markov chain. The transition matrix describes how likely each base is to mutate to another over time.
🤖
Language Models
Early autocomplete was a Markov chain over words. Modern AI goes further — but the root idea, "predict the next token from the current context," traces directly back here.
🎲
MCMC Sampling
Markov Chain Monte Carlo constructs a chain whose stationary distribution is any target distribution you want. Used throughout statistics, physics, and Bayesian ML.
You've built the theory from scratch: states → Markov property → transition probabilities → transition matrix → stationary distribution → state classification.
